Admin login

Sign in with a one-time email link to manage project photos. Only the authorized admin email can use these tools.

One-time setup needed

The sign-in and photo storage are not enabled until the Supabase project settings are added.

  1. In supabase-config.js, replace the project URL and public publishable/anon key placeholders. That public key is designed for browser use; never put a service-role key here.
  2. Run supabase-setup.sql in your Supabase SQL Editor to create the photo table, public read access, and admin-only write policies.
  3. In Supabase Authentication URL settings, set the site URL to https://mokshagnen2008.github.io/sr-solar-site and add https://mokshagnen2008.github.io/sr-solar-site/admin.html as an allowed redirect URL. Enable email sign-in.
  4. After configuring Supabase, publish the updated settings to the existing GitHub Pages repository. Sign-in stays disabled until valid settings are configured.

The one-time link will be sent only to the authorized email above. No password is stored by this website.
