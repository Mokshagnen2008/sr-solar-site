Supabase setup checklist

Check these one-time settings if sign-in or photo management is not working:

  1. Confirm supabase-config.js contains the Supabase Project URL and public publishable/anon key. The public key is designed for browser use; never put a service-role key here.
  2. Run supabase-setup.sql in your Supabase SQL Editor to set up photo management, secure visit counts, and private contact inquiries.
  3. In Supabase Authentication URL settings, set the site URL to https://mokshagnen2008.github.io/sr-solar-site and add https://mokshagnen2008.github.io/sr-solar-site/admin.html as an allowed redirect URL. Enable email sign-in.
  4. After changing the config, publish the update to the existing GitHub Pages repository.

The link is sent only for the authorized admin email. Select it in your inbox to verify the session; no password is stored here.
